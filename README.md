# Near Me Cafe — premium e-commerce demo

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Keep the `assets` folder beside `index.html`.

## Included
- Responsive premium cafe storefront
- 22 menu entries from the supplied menu list
- Search and category filters
- Add-to-bag, quantity controls, subtotal and demo delivery fee
- Checkout form validation and demo order confirmation
- Responsive mobile navigation, scroll reveal animation and hover effects
- Supplied cafe-front, sandwich and burger photographs in `assets/`

## Important demo limitations
- Checkout is a front-end demonstration only. It does not send orders to the cafe or collect payment.
- Real ordering requires a backend/API, secure order storage, restaurant acceptance workflow and a payment provider if online payment is needed.
- The cafe address, business hours, exact menu prices and item photography should be verified by the cafe owner before publication.
- Some food cards use remote Unsplash images as temporary illustrative imagery. An internet connection is needed for those images and Google Fonts. Replace them with owner-approved food photos before client delivery.
- Bombay Vada Pav and Veg Puff show multiple price options. The menu uses the supplied figures; confirm sizes and prices with the business.
